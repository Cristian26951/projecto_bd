¿Qué puedes hacer con Mi Tienda?

Un panel sencillo para llevar el control de tus productos y mantener la comunicación con tus clientes.

Registro de productos

Agrega nuevos artículos con su nombre, precio y cantidad disponible desde un formulario rápido y validado.

Edición y eliminación

Actualiza la información de cualquier producto o elimínalo cuando ya no esté a la venta, con cambios guardados al instante.

Control de stock

Consulta la lista de productos con su precio y existencias para saber qué tienes disponible y qué necesitas reponer.

Mensajes de contacto

Tus clientes pueden escribirte desde la página de contacto, y tú puedes buscar y revisar los mensajes recibidos.

Datos en MySQL

Toda la información se almacena en una base de datos MySQL, así tus productos y contactos se mantienen seguros y persistentes.

API con Node.js y Express

El frontend se comunica con un servidor Express que expone las rutas para crear, leer, actualizar y eliminar registros (CRUD).
